Repozytorium jest publiczne, więc każde zapisane w nim hasło lub klucz dostępu może odczytać każdy, także automaty, które stale przeszukują GitHub w poszukiwaniu kluczy. Za taki wyciek odpowiada autor repozytorium, nie GitHub. Samo usunięcie pliku nie wystarcza, bo Git przechowuje całą historię zmian: hasło nadal jest widoczne w starszym zatwierdzeniu, a każdy, kto wcześniej sklonował repozytorium, ma je u siebie. Jedynym skutecznym ratunkiem jest natychmiastowa zmiana hasła lub unieważnienie klucza.
